why telinha

⚡

Fast

Capture, encoding and decoding stay on the GPU. Latency is measured on every frame, and the stream adapts before a delay builds up.

🔗

One invite, done

The invite carries every way into the room (LAN, router port, IPv6, public link). Each person joins through the fastest one that works.

🔒

Private

Every connection encrypted with X25519 and ChaCha20-Poly1305, with the password in the key derivation. The server's identity is verified.

🪶

Light

The interface only redraws when something changes. Features you don't use cost nothing: no CPU, no GPU, no bandwidth.

📦

Portable

On Windows it's a single .exe. On Linux it runs on Wayland and X11, on any distro with glibc 2.31+.

🔄

Updates itself

Shows what changes, checks the release signature and swaps its own executable. One click, or on its own.

install

pick your system

No sudo: downloads the latest release, checks its SHA256, puts telinha in ~/.local/bin, adds it to your app menu and makes telinha:// invites open in the app. Run it again to update.

$ curl -fsSL https://raw.githubusercontent.com/RshaCuDeVidro/telinha/main/install.sh | sh

Download telinha-windows-x86_64.exe and run it. Nothing to install. SmartScreen warns on first launch (the .exe isn't signed): More info → Run anyway.

# optional: check the file against the release's SHA256SUMS
PS> Get-FileHash .\telinha-windows-x86_64.exe

An always-on room on a VPS: a static binary with no dependencies. With --web and --web-tunel, everyone can watch from a browser. Full guide →

$ curl -fsSLo telinha-server {{gh}}/releases/latest/download/telinha-server-linux-x86_64
$ chmod +x telinha-server
$ ./telinha-server --porta 7777 --senha secret --web 7778 --web-tunel

in 5 steps

full guide →

  1. Create a room. Open telinha and click Create room. The password is optional.
  2. Invite people. Open port on router for a direct connection, or Create public link if your ISP uses CGNAT. Then Copy invite.
  3. Join. Whoever gets it pastes the telinha://… invite on the home screen. If it's already copied, it pastes itself.
  4. Go live. Share screen, pick what to show, the sound and the quality, then Go live. Everything can change mid-stream.
  5. Watch and talk. Click anyone who is live. F11 fullscreen, Ctrl+M microphone, Ctrl+D deafen.
