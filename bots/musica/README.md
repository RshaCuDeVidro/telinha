# Bot de música / Music bot

Toca música na call do telinha: pasta, arquivos da sala, rádios.
Plays music in a telinha call: a folder, room files, radios.

```sh
python3 -m venv .venv && .venv/bin/pip install ./sdk/python
.venv/bin/python bots/musica/musica.py "telinha://minha.sala:7777#senha" --pasta ~/Música
```
